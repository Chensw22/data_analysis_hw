# 联合乘客清单里的消费关联能否纠正反复错例？

从全体 12,970 人的无标签登记和消费分档构建乘客与属性取值的关联矩阵，用多重对应分析学习 14 个主方向。逐个遮住字段，根据其余字段重建真实取值，用重建误差和主方向坐标与个人特征共同预测结局。打乱关联的对照保留每个字段的分布、使用相同的维数和分类器。在 2,609 名来自独立订票组的乘客上，真实关联在全部 14 个字段的重建损失都低于打乱对照，平均分别为 1.294 和 1.763。区间分档从无标签全名单确定。

在 6,954 人的三套按订票组留出的划分上，实际分类结果如下。纠正和新增错误均相对同一强基线。

| 方法 | 全体准确率 | 纠正 / 新增错误 | 335 名只有弱模型能稳定答对的乘客中答对 | 252 名无历史候选答对的乘客中答对 |
|---|---|---|---|---|
| 仅个人特征 | 81.10% / 80.89% / 81.05% | 179/225、161/192、190/213 | 34 / 29 / 39 | 0 / 0 / 0 |
| 个人与真实关联 | 80.90% / 80.43% / 80.70% | 217/277、210/273、223/270 | 47 / 48 / 51 | 1 / 0 / 1 |
| 真实关联候选占强基线混合的 25% | 81.77% / 81.25% / 81.32% | 68/68、62/68、66/70 | 5 / 4 / 7 | 0 / 0 / 0 |

335 人中，加入真实关联后有 8 人三次都答对，单用个人特征有 1 人，打乱关联却也有 18 人。252 人中没有人被新模型连续三次答对。模型能利用清单关联重建看不见的字段，仍未取得整体分类净收益。[三次验证和无标签重建结果](result.json)
