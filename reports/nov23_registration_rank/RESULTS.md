# 在相似账单间学习登记差异，能修复多少漏判？

对每名训练乘客，先按五项消费金额与缺失/正值状态找其他预订的近邻，再用两人实际结果相反的配对学习登记字段之间的差异。每个外层训练折提供约 1.4 万个这样的配对。验证时只借用训练乘客的结果，用新乘客相对近邻的登记得分调整其传送概率。每套在 6,954 名乘客上验证。

| 判断方式 | 三套准确率 | 每套纠正 / 误伤 |
|---|---|---|
| 仅按相似账单借用结果 | 78.11% / 78.17% / 77.93% | 230 / 484，250 / 470，251 / 491 |
| 加入通过配对学到的登记差异 | 78.11% / 78.34% / 78.44% | 307 / 561，310 / 518，335 / 539 |
| 配对模型固定占强基线的 25% | 81.55% / 81.41% / 81.45% | 82 / 97，85 / 80，97 / 92 |

配对模型独立使用时，在 267 名共同漏判中分别救回 15、10、10 人，但全体误伤太多。加入强基线后，在这 267 人中三套均未救回任何人。[完整结果及普通登记模型对照](result.json)
