# run_013：严格嵌套的两模型融合

v25空间专家与TabPFN compact8的两列logit，在每个外层训练折内部重新生成三折OOF并训练固定C=1逻辑回归。完整结果81.53581%，低于v25的81.86655%及run012最佳81.92407%。未通过83%门槛。

外层三折82.52761%、81.36324%、80.71613%，总训练/预测约284秒。元模型在三折中对空间专家的系数约0.530、0.164、0.229，对TabPFN约0.452、0.791、0.751，显示内层相对表现存在波动；不根据这些结果重新选择权重或正则。

人工审查及自动边界测试确认：内层拟合不接触外层验证行、元模型只使用内层OOF、全外层训练集重训后才预测验证集。没有将已有全开发集OOF同时用于拟合和评分。未再次使用旧留出集，未提交线上。
