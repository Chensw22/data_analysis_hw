# 订票编号顺序和共同错误

官方训练集和测试集各有 6,217 和 3,063 个独立订票组，没有订票组跨两侧。按编号升序排列后，没有检测到异常的测试组聚集。订票编号能还原排列顺序，数据本身无法验证它对应的真实时间。

在每个实际组大小内随机交换官方训练、测试标记 3,000 次，保留每种大小的测试组数。对所有连续 32、128、512 组的窗口联合扫描，最极端偏差的置换 p 值为 0.773。举例来说，连续 32 组中测试组最少为 2 个（4873 至 4904），最多为 20 个（1466 至 1497）。最长连续测试段为 8 组（p = 0.588），相邻两组均为测试组的频数也落在随机基线内（p = 0.677）。

在 6,954 名有折外预测的开发乘客中，以每个订票组左右各 64 组的测试密度衡量周边测试分布，排除该组本身。按订票组汇总错误率，并在相同组大小、相同开发集成员数内置换 2,000 次；参考模型错误率、历史共同错 941 人、其中 696 个消费规律例外的关联 p 值依次为 0.860、0.782、0.393。

将连续编号段内的开发乘客权重校准至官方测试乘客的实际占比，比较 50 项归档候选三个随机种子的平均准确率：

| 连续订票组数 | 参考准确率 | 排名 Spearman 相关 | 任意两候选差距的最大改变量（百分点） |
| ---: | ---: | ---: | ---: |
| 不加权 | 81.493% | 1.0000 | 0 |
| 32 | 82.007% | 0.9956 | 0.541 |
| 128 | 81.551% | 0.9976 | 0.288 |
| 512 | 81.469% | 0.9994 | 0.163 |

三个尺度下首位都是 `rule_context_pool`。128 组尺度上，两个共同错误集合占比只改变 −0.058 和 −0.093 个百分点。最窄窗口重加权的有效样本量降到 5,641，该尺度自身带有更大的抽样波动。实际测试乘客没有公开标签，以上为分布敏感性分析；目前没有证据支持按订票顺序改变整体模型选择。
