# 综合两种消费表示后，是哪些预测在变好？

保留强基线模型，同时加入一个保留个人信息、消费总额及五项服务各自的缺失/零/正状态，但隐去五个具体金额的候选模型。两者在每套验证里都对全部 6,954 人作出折外预测。用独立预订学习二维单调概率曲面，并和同一批乘客上的固定 25% 混合、单独校准强基线和条件打乱的第二模型比较。

| 判断方式 | 三次准确率 | 相对基线净多判对 | 三次均修正的持续漏判 |
|---|---|---|---:|
| 强基线 | 81.77% / 81.33% / 81.38% | 0 / 0 / 0 | 0 |
| 两种概率联合校准 | 82.05% / 81.65% / 81.44% | +20 / +22 / +4 | 0 |
| 隐去各项金额的模型固定占 25% | 82.00% / 81.78% / 81.49% | +16 / +31 / +8 | 1 |
| 单独校准强基线 | 81.75% / 81.58% / 81.39% | −1 / +17 / +1 | 0 |
| 在相似基线概率内打乱第二模型再联合校准 | 81.67% / 81.54% / 81.51% | −7 / +14 / +9 | 0 |

二维联合校准在三次中分别找回 51、24、35 个漏判，同时新增 32、25、41 个误报。对 480 名三次都漏判的乘客，每套分别修对 23、2、9 人，三套的交集为零。在另一方向上分别修正 50、113、89 个误报，并新增 49、90、79 个漏判。第一套上两类贡献差异很大，后两套的净收益都主要来自修正误报。

三套先对每位乘客的差值求均值，再以完整预订为单位重抽 3,000 次，联合校准平均提高 0.220 个百分点，95% 参考区间为 −0.058 至 +0.485；固定 25% 混合提高 0.264 个百分点，区间 +0.010 至 +0.516。这里只重抽已有验证预测，未重新训练模型；同一批乘客参与过模型开发。与 85% 目标之间的差距仍超过上述增幅。[成对统计](paired_summary.json)

每个外层验证折内，两种底层预测都来自没有见过该折任何预订的模型。再将该折的预订分成三组，用其中两组训练校准器，预测另外一组。所有候选共享这套评估；固定四分之一混合无需校准训练。打乱对照只在同一基线概率档内置换第二模型的概率，并分别置换校准与验证乘客。原始逐方向计数和概率误差可复查。[完整计数](result.json)
