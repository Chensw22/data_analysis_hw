# 登记信息中有哪些是账单推不出来的？

以全部乘客的五项消费为输入，分别估计传送概率以及登记字段（含两两组合）的预期情况。每名训练乘客获得的估计都来自未见过其预订的模型。将实际登记减去按账单预测的登记表示，观察这个差值能否修正账单给出的概率。另与直接加入原登记字段及在相近账单预测风险内随机打乱差值作对照。

| 输入 | 三套独立模型准确率 | 占强基线 25% 后的准确率 |
|---|---|---|
| 仅账单 | 79.41% / 79.48% / 79.55% | 81.45% / 81.23% / 80.92% |
| 账单加原登记字段 | 79.91% / 80.21% / 80.67% | 81.48% / 81.45% / 81.36% |
| 账单加登记差值 | 79.95% / 79.90% / 80.27% | 81.85% / 81.35% / 81.35% |
| 打乱登记差值 | 79.49% / 79.11% / 79.21% | 81.41% / 81.19% / 81.06% |

登记差值相对打乱对照三套都有价值，但并入强基线后，全体净多判对 6、1、−2 人。480 名持续漏判中各套找回 16、10、14 人，267 名共同漏判中分别找回 1、0、0 人。[分方向结果](result.json)
