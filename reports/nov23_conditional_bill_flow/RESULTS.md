# 从传送与未传送两种结局分别推算消费账单

在全部开发乘客上分别估计两种结局对应的账单分布。先估计登记信息对应的传送概率，再依次预测每笔账单是缺失、零消费还是正消费，最后拟合正金额的联合分布。独立高斯分布和四层可逆变换共用离散状态模型与训练样本。金额按对数尺度视为连续值，只有实际为正的金额进入密度。另用自动微分检验了全部正金额及部分正金额两种情况下，可逆变换的雅可比行列式与实现一致。[可逆仿射变换的原始论文](https://arxiv.org/abs/1605.08803)

| 使用的账单证据 | 三次全体准确率 | 与强基线按 25% 权重混合后的全体准确率 |
|---|---|---|
| 只用离散状态 | 74.65% / 74.48% / 74.35% | 81.41% / 81.49% / 81.22% |
| 加入各正金额的条件高斯密度 | 78.23% / 78.23% / 78.23% | 81.41% / 81.26% / 81.12% |
| 加入正金额的条件联合密度 | 78.59% / 78.62% / 78.49% | 81.44% / 81.21% / 81.08% |

正金额能帮助区分结局。在这个模型内，联合密度比独立高斯密度依次多答对 25、27、18 人。联合密度单独使用时，在 1,070 名全体反复错例中依次救回 149、137、156 人；在全部乘客上依次纠正 233/225/255 人，同时新增错误 454/414/456 人。四分之一混合整体净增 −23/−9/−21。[全部指标](result.json)
