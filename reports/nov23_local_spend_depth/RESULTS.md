# 相似乘客中的联合消费异常

在 6,954 名开发乘客中，用 80 名登记信息相似乘客的账单分布衡量消费搭配有多反常。372 名长期共同错例中，三套整组划分里曾经预测对 5 人，包括 4 名独自订票者，但每人都只在一套划分中预测对。以 25% 权重加入现有参照后，这 5 人全部失去修复，整体也未提高。

| 输入与预测方式 | 整组 11/12 | 整组 11/15 | 整组 11/16 | v131 回放 | 三组均修复 / 曾修复的共同错例 |
|---|---:|---:|---:|---:|---:|
| 现有参照 | 81.77% | 81.33% | 81.38% | 81.42% | 0 / 0 |
| 原始登记与账单 | 80.83% | 80.76% | 80.90% | 80.49% | 0 / 0 |
| 加五种服务各自的条件分位 | 80.80% | 80.73% | 80.80% | 80.40% | 0 / 2 |
| 再加逐项重排账单的组合分位 | 80.70% | 80.67% | 80.47% | 80.08% | 0 / 3 |
| 再加真实账单的组合分位 | 80.86% | 80.72% | 80.44% | 80.05% | 0 / 5 |
| 参照混合 25% 真实组合模型 | 81.78% | 81.28% | 81.36% | 81.19% | 0 / 0 |

真实账单模型单独预测时，相对现有参照三套整组划分分别纠正 179、177、176 人，同时误伤 242、220、241 人。加入参照后分别纠正 53、55、57 人，误伤 52、59、58 人。v131 回放纠正 67 人，误伤 83 人。以订票号为单位，对同一乘客三套预测的平均正确率差进行配对自助抽样，混合模型相对参照的 95% 区间为 −0.20 至 +0.17 个百分点。真实搭配对照逐项重排的独立模型区间为 −0.23 至 +0.35 个百分点。

每个外折仅用训练折确定登记字段的距离刻度、账单缺失填充值与近邻候选。每人排除本人整个订票组后寻找邻居。五种服务账单取对数，计算任意两项的和与差、五项总和及住宿服务和餐饮购物之间的预设对比，共 22 个方向。特征包含条件中点分位数、与乘客同值的比例以及跨方向尾部强度。逐项重排对照在同一组邻居内独立打乱每列，因此五种单项分布完全保留，22 项组合反映的依赖结构被破坏。所有对照共用相同的梯度提升树参数。原始缺失标志由树的缺失分支处理。全程未使用姓名、近邻结果标签或验证标签构造特征。

历史的条件分位森林测量逐种服务的分布，向量分位实验使用宽登记分层内的最优传输。本轮专门检验个人登记近邻中真实五项账单的组合尾部，覆盖单人及多人订票。以上均为开发集复用结果。各版本的完整配对数据见同目录的 `results.json`，逐行概率由 `broad_local_spend_depth_n23.py` 输出至本地缓存。
