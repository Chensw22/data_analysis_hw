# 延长后验采样后的贝叶斯树

模型、数据、特征与随机种子沿用短链实验，每链预热由 50 延长到 360，保留的后验样本由 64 增加到 384。每折两条链给同一乘客的概率差，中位数从 0.033–0.035 下降至 0.025–0.027，95% 分位从 0.154–0.160 下降至 0.134–0.145。

| 三套分组验证 | 准确率 |
|---|---|
| 短链 BART 单模 | 80.54% / 80.10% / 80.46% |
| 长链 BART 单模 | 80.86% / 80.85% / 80.83% |
| 同特征梯度提升树 | 81.13% / 81.09% / 81.02% |
| 长链 BART 固定占强基线 25% | 81.71% / 81.45% / 81.41% |

延长采样提高了单模精度。加入强基线后全体净变化为 −4、+8、+2 人，仍未形成稳定且有实际幅度的提升。运行命令为 `.venv/bin/python bayesian_manifest_forest_n23.py --long-chain`。[全部数值](result.json)
