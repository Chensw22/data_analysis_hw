# 哪些训练乘客能使模型在其他订票组上少犯错？

在每个外层训练折内，将订票组分为两半。在一半的乘客上模拟一次参数更新，使用另一半的结局计算这次更新对分类误差的影响；以此决定每个训练例的权重，然后两半交换角色。最终在另行留出的订票组上预测。使用均匀权重和在训练批次内打乱已算权重作对照。相同的随机种子、批次、网络和优化器贯穿三种方法。方法借鉴可微分的单步样本重加权，在此使用平滑分类误差和对数损失作为反馈。[Ren 等人的原始研究](https://proceedings.mlr.press/v80/ren18a.html)

| 权重 | 整体准确率 | 1,070 名反复错例三次分别纠正 | 与强基线按 25% 混合后的整体准确率 |
|---|---|---|---|
| 均匀 | 79.90% / 80.07% / 79.77% | 139 / 126 / 128 | 81.54% / 81.28% / 81.15% |
| 学习后打乱 | 80.17% / 79.74% / 79.84% | 122 / 140 / 134 | 81.46% / 81.23% / 81.22% |
| 学习后应用于原训练乘客 | 79.94% / 79.91% / 79.87% | 132 / 113 / 121 | 81.48% / 81.16% / 81.13% |

与均匀训练相比，按估计的贡献重加权分别净增 3、−11、7 个正确预测。单独使用时分别纠正强基线 215/200/221 人，同时新增错误 342/299/326 人。[逐次人数和错误范围](result.json)
