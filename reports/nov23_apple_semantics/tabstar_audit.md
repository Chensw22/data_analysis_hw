替代实验使用 Apple Natural Language 内置的通用英语词向量，只向模型查询固定词表的单词向量，随后在本地将乘客数据编码并按预订分组验证。Apple 将这一模型描述为从通用文本预训练的词嵌入。[Apple 词嵌入说明](https://developer.apple.com/documentation/naturallanguage/finding-similarities-between-pieces-of-text)

## 本地验证

在同一批 6,954 名开发乘客上采用三套按预订分组的三折验证，每套每人恰好进入验证一次。所有模型使用 13 个原始字段；语义模型额外加入 16 个自词向量计算的数值特征，置换对照在各字段内部重新分配类别含义，并轮换五项消费服务的含义。三套依次采用 20261112、20261115、20261116 切分。1,070 人是三个历史参照都判错的乘客，466 人是其中所有历史挑战模型也都错的乘客，属于回顾性分析样本。

| 方法 | 三套验证准确率 | 1,070 人中三套均正确 | 466 人中三套均正确 |
| --- | --- | ---: | ---: |
| Mitra 与 v44 等权参照 | 81.766% / 81.334% / 81.378% | 0 | 0 |
| 原始类别 | 81.119% / 80.270% / 80.659% | 15 | 0 |
| 真实词义 | 81.191% / 80.544% / 80.400% | 19 | 0 |
| 置换词义 | 81.090% / 80.630% / 80.500% | 22 | 0 |
| 75% 参照 + 25% 真实词义 | 81.823% / 81.378% / 81.162% | 1 | 0 |
| 75% 参照 + 25% 置换词义 | 81.852% / 81.406% / 81.191% | 0 | 0 |

真实词义模型单独在三套验证中分别修对 110、97、83 个历史共同错误，修对最难的 5、4、5 人，三套反复修对的最难案例为零。真实词义与参照混合后，分别修对 44/50/38 个参照错误，同时将 40/47/53 个参照原本正确的预测改错。因类别文本有限，部分专名和甲板字母没有词向量，例如 Europa 的表示仅来自通用词 moon。这一编码未显示可复现的净收益。
