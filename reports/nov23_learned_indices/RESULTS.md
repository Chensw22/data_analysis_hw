# 联合学习投影方向和响应曲线能否纠正共同错误？

在 6,954 人开发集上，独立预测模型使用一个线性基底及七个一维非线性函数。每个函数作用于年龄、舱位、消费等字段的一个线性组合上，以六个高斯基函数表示其形状。初始方向来自训练乘客两类均值与协方差的差异，复用此前固定投影方法的方向估计。新模型直接按分类对数损失联合更新七个方向与六项形状系数。固定初始方向的对照使用完全相同的迭代、批次与其余权重更新。三个外层验证分开整笔订票；v131 原划分也从新主干训练中移除评估组。组合仅用同一外折内的其他订票组学习，保留 v131 已有改判。

| 预测方法 | 三次全体纠正 / 新增错误 | 1,070 人中稳定纠正 | 509 / 172 名难例中稳定纠正 |
|---|---|---:|---:|
| 线性 | 235/389、218/356、234/352 | 116 | 12 / 1 |
| 固定投影，只学响应形状 | 244/355、237/344、230/350 | 104 | 8 / 0 |
| 联合更新形状与投影方向 | 244/373、246/355、260/385 | 70 | 2 / 0 |
| 强基线与固定投影模型组合 | 57/70、84/63、60/73 | 1 | 0 / 0 |
| 强基线与联合更新模型组合 | 57/63、83/72、51/65 | 3 | 0 / 0 |

联合更新模型独自稳定救回 22 名两种对照都未稳定纠正的反复错例，包括 16 名单人订票者、5 名有消费的漏判乘客。其三次全体准确率为 79.91%、79.77%、79.58%；融合后为 81.68%、81.49%、81.18%。v131 回放纠正 82 人，新增错误 95 人，准确率 81.23%。三套分组使用同一批开发乘客。[全体、订票组和错例层明细](results.json)

另生成 18 个高斯字段，把其中三个未知旋转方向经过非线性函数后相加生成结果。用 4,500 个样本拟合并预测另外 2,500 个样本，线性模型准确率为 64.80%，固定方向模型 70.12%，联合学习方向的模型 78.88%，真实生成概率直接分类为 80.36%。方向梯度经独立差分校验。联合学习能在这种结构存在的模拟数据上提取信号，在真实竞赛数据上未获得相同收益。[模拟结果](control.json)
