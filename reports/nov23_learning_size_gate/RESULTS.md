# 增加训练乘客后的分数变化能识别哪些错误？

在 6,954 名乘客的八折整订票组验证中，给四个模型增加约 1,450 名训练乘客后，可以用它们预测变动的方向再做判断。这个变化确实能救回一批此前反复判错的人，但相对只使用四个模型的大训练集分数，全体纠正 47 人、新增 59 错。按订票组配对重采样，全体变化为 −0.17 个百分点，95% 区间为 −0.47 至 +0.10 个百分点。

| 方案 | 全体准确率 | 相对大训练集参照纠正 / 新增错误 |
|---|---:|---:|
| 大训练集 v44 与 TabICL 各半 | 81.81% | 0 / 0 |
| 大、小训练集参照概率取平均 | 81.64% | 41 / 53 |
| 参照在对数几率上沿原方向再走同样一步 | 81.82% | 112 / 111 |
| 用四个模型的大训练集分数修正参照 | 81.92% | 55 / 47 |
| 再加入四个模型从小到大的分数变化 | 81.75% | 75 / 79 |

按强基线在此前三次分组验证中的表现，所有人分为下面三组。分组只用于事后统计。纠正和新增错误都在这次八折的同一名乘客上配对计数。

| 历史表现 | 人数 | 有轨迹相比只用大训练集分数，纠正 / 新增错误 | 直接外推相比参照，纠正 / 新增错误 |
|---|---:|---:|---:|
| 三次都正确 | 5,436 | 3 / 24 | 11 / 62 |
| 有对有错 | 448 | 25 / 26 | 44 / 39 |
| 三次都错 | 1,070 | 19 / 9 | 57 / 10 |

四个模型为 v44、TabICL、常规 CatBoost 和蒸馏 CatBoost。此前的训练量实验比较各模型自身的命中率，本次单独检验把预测变化提供给决策模型是否有增益。每个外折的基础模型使用约 4,636 人及包含这批乘客的 6,067 至 6,114 人训练，两批均排除整组评估乘客。修正模型在该外折内部再分三个互斥订票组子折，每次用两个子折校准、第三个子折计分；两个学习方案使用同样的先验、特征标准化和惩罚。上述外推步长固定为一，未经选优。首次核验因把数字预订编号转换成未补零的字符串而改变分折排序，脚本在拟合前中止。改用原数字编号后已逐折核对评估行号和训练人数。

运行 `.venv/bin/python learning_size_gate_n23.py` 可复现。输入来自 `near_full_crossfamily_distillation_n23.py` 的八折缓存，以及 `broad_partition_evidence_n23.py` 读取的历史评估划分。[逐折计数和区间](result.json)
