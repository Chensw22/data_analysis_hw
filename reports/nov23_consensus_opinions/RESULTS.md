# 模型结论一致时，概率分歧还能识别例外吗？

在每个验证折中，对基线与八类模型都给出相同预测的乘客，按预测传送与预测未传送分开评估。先扣除基线风险能够解释的其他模型概率变化，再分别学习真实例外和正常结果下八项概率的分布。用多元 t 分布估计各模型概率联合变化的证据，用互不重叠的预订校准证据强度，最后在另一批预订上作出判定。有模型意见相反的乘客继续使用基线。

| 全体 6,954 人 | 三套相对基线纠正 / 误伤 | 对一致判阴的人排序找出漏判的 AUC |
|---|---|---|
| 强基线 | — | 0.690 / 0.702 / 0.698 |
| 仅校准基线 | 2 / 2，3 / 3，1 / 4 | 0.690 / 0.697 / 0.701 |
| 分开使用各模型的概率证据 | 2 / 3，3 / 4，3 / 2 | 0.695 / 0.695 / 0.705 |
| 同时使用各模型间的概率关系 | 2 / 2，5 / 4，2 / 2 | 0.698 / 0.697 / 0.704 |

联合概率证据只净多判对 0、1、0 人。即便分类票数完全相同，原始概率仍有一定排序能力；这次实验没有让排序或准确率获得可重复的上升。[原始结果](result.json)
