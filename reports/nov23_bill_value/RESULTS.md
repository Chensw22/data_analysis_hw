# 能否从乘客资料判断什么时候该降低消费权重？

验证覆盖 6,954 名乘客。用同一棵树的两种训练方案分别预测，一种使用全部字段，一种去掉五种消费金额。对每名乘客估计不看消费的模型应占多少权重，每个外折都在其余订票组的内部折重新训练两种树，用内部留出概率学习组合权重。方法对所有乘客输出预测。检验的输入依次是两个模型的概率、实际登记与消费字段、这份账单在 64 名登记资料相似的训练乘客中所处的位置。对照在消费与模型意见相似的人之间打乱账单相对位置。没有把历史错例分组送入模型。

八模型三次共同判错的 332 人中，之前完全去掉消费能稳定救回 30 人，同时使八模型原来三次都对的 4,144 人中有 271 人三次都错。本轮加入消费相对位置后，这两批人中稳定判对分别为 0 和 270。该权重对两批乘客的描述性排序 AUC 是 0.575、0.582、0.719，但他们是按已知结局事后挑出的，不能由这些数推断全体改判收益。
