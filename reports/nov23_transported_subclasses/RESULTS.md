# 给运输结果学习四个子类别

先将实际传送、实际未传送各拆成两类，然后用乘客自身 13 项字段做四分类，最后把两个传送子类的预测概率相加。比较两种拆分：按内层独立预订中一棵树是否容易判对该人，或在每个真实结果中按该人的属性聚类。对照包括普通二分类，以及在每个运输结果内部随机打乱难易标记。训练用的难易标签来自外层训练集内部按整份预订的交叉预测，每名验证乘客的真实结果只用来评估。每套验证覆盖 6,954 人。

| 训练目标 | 三套准确率 | 找回 480 名持续漏判中的人数 | 其中 267 名共同漏判中判对人数 |
|---|---|---|---|
| 普通二分类 | 81.12% / 80.49% / 80.89% | 24 / 22 / 30 | 0 / 0 / 0 |
| 易错与易对分开学习 | 80.62% / 80.30% / 80.57% | 28 / 19 / 32 | 0 / 0 / 1 |
| 类别内聚类 | 80.90% / 80.92% / 80.66% | 25 / 29 / 34 | 0 / 0 / 0 |
| 类别内打乱难易 | 80.95% / 80.49% / 80.43% | 33 / 24 / 35 | 0 / 0 / 0 |

只允许难易模型把基线的未传送改成传送时，三套分别找回 80、58、85 个漏判，同时新增 90、81、107 个误报。训练时把难例作为独立子类没有带来稳定收益。[分方向与单人预订统计](result.json)
