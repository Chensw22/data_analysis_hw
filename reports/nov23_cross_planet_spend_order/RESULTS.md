# 其他出发地的消费排序能否迁移给地球乘客？

在每个外层训练折，仅用 Europa 和 Mars 乘客训练排序器。在相同出发地、休眠状态、年龄档、总额档和账单缺失状态内，将不同订票的旅客随机配对，用实际结局相异的配对学习如何从五项消费的分配辨别谁更可能被传送。另用地球训练旅客和配对方向打乱的非地球训练旅客训练对照。排名检验在陌生地球订票组进行，只统计消费特征有差别且结局不同的配对，三次分别有 513、506、463 对。三次验证重复评估同一批乘客。

| 评分依据 | 三次地球配对排序正确率 |
|---|---|
| 只在 Europa 和 Mars 上学到的消费排序 | 73.10%、73.12%、71.92% |
| 只在地球上学到的消费排序 | 73.88%、69.37%、72.35% |
| 打乱非地球配对的结局方向 | 52.63%、59.09%、52.48% |
| 现有强基线综合评分 | 79.73%、79.64%、80.99% |

非地球消费排序对地球乘客有可迁移的信息，但许多信息已反映在强基线里。用各外层验证折里独立的地球订票组学习如何把排序合入强基线，其他出发地维持原始预测。相对未经校准的强基线，分别纠正 44/84/35 人，新增错误 32/56/22 人，整体准确率为 81.94%、81.74%、81.56%。其中修正漏报 20/33/13 人，修正误报 24/51/22 人，新增漏报 12/36/12 人，新增误报 20/20/10 人。

相对同样只在地球上校准的强基线，消费排序仅多答对 2/2/8 人；按完整订票组重抽，三轮平均提高 0.058 个百分点，95% 区间为 −0.039 至 +0.162 个百分点。249 名地球乘客属于原先弱模型可救集合，三次答对 4/11/5 人；179 名地球共同难例中，三次均为 0 人。[计数与完整对照](result.json)
