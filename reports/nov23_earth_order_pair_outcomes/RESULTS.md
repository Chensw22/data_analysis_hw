# 在看到查询乘客结局之前，识别消费反例

从全部地球乘客出发，以五笔消费可比较、缺失位置相同为条件，在其他训练订票组寻找支出方向更低、更高或相同的相似乘客。先按可观测特征选配对，再读取训练乘客的已知结局。训练一个四分类模型联合预测一对乘客的结局，然后根据已知乘客的真实结局，计算另一人被传送的概率。两种对照分别将已知乘客的结局隐藏、在训练乘客中随机打乱。每套评估覆盖 3,644–3,645 名地球乘客，未找到可比对象者和其他出发地沿用基线。

三套验证中，严格可比、且已知乘客的结局允许发生反例的配对有 7,714、7,665、7,676 对，实际出现 2,795、2,818、2,805 对反例。每名查询乘客可对应多名训练乘客。识别反例的折内 AUC 为 0.800–0.854，同样问题直接使用基线概率为 0.808–0.869，九折中有八折由基线排序更准。

| 对全部 6,954 人的预测 | 三次准确率 | 三次纠正 / 新增错误 |
|---|---|---|
| 隐藏训练伙伴结局，只用四状态模型的边际概率 | 81.72% / 81.46% / 81.25% | 133/136、111/102、123/132 |
| 按训练伙伴真实结局计算条件概率 | 81.68% / 81.51% / 81.26% | 126/132、107/95、128/136 |
| 条件概率占 25%，其余沿用基线 | 81.69% / 81.59% / 81.45% | 25/30、35/17、32/27 |

用真实伙伴结局的模型在 804 名地球反复错例中分别纠正 66、55、65 人。三次对全体乘客的净增分别为 −6、+12、−8。[全部配对统计及打乱对照](result.json)
