# 比较同类乘客账单在两种结果下的分布

覆盖全部 6,954 名开发集乘客。以非账单属性为输入，训练多输出随机森林预测五项账单、零消费和缺失状态。每棵树的叶子中，用未参与建树的订票组估计账单的双侧经验秩和并列值的概率。在同一批叶子上，一次按假定的乘客结果分别估计分布，一次忽略该结果作为对照。两者都使用相同的缺失状态和并列处理。每个外折内再按订票组分开学习与检验分类组合。模型使用开发集账单、乘客属性和训练标签，未使用姓名和封存标签。

| 方法 | 三次准确率 | 在 1,070 名基线重复错例中稳定纠正 | 在 212 名历史 46 种模型全错中至少对一次 / 稳定纠正 |
|---|---|---:|---:|
| 仅用强基线分数重新校准 | 81.88%、81.90%、81.10% | 3 | 0 / 0 |
| 强基线加不分类别的账单秩 | 81.03%、81.05%、80.96% | 30 | 0 / 0 |
| 再加类别条件下的账单秩差异 | 80.50%、80.64%、80.50% | 43 | 1 / 0 |
| 单独用两类账单秩及合并秩 | 78.44%、78.09%、78.21% | 96 | 6 / 0 |

在相同的合并秩对照上添加类别条件差异，全体乘客分别纠正 72、80、70 人，同时新增 109、108、102 个错误。相对最初的强基线则分别纠正 173、191、192 人，同时新增 261、239、253 个错误。账单分布差异能解释部分重复错例，但当前组合无法把收益推广到全体乘客。

逐人与历史 46 个候选对齐，独立账单模型新稳定纠正 13 名从未被任一历史候选稳定纠正的重复错例；与强基线组合后为 3 名。
