# 用客票之间的结果关系训练神经网络

对每位训练乘客抽取六位其他预订的乘客，其中三位账单相近，三位随机抽取。共享编码器表示两人，再用两人的特征和、绝对差、乘积学习两人是否经历相同结局。预测时分别与训练集中各 64 名已传送与未传送乘客比较，由独立的校准预订将相似得分转换为概率。控制实验使用相同乘客、编码、训练轮数与直接分类目标，其中一组打乱用于训练关系的参考乘客标签。外层验证乘客的预订从所有训练、参考和校准部分留出。

| 模型，所有 6,954 人 | 三套准确率 | 267 名共同漏判中各套正确 |
|---|---|---|
| 直接训练的神经网络 | 79.94% / 79.52% / 79.49% | 2 / 3 / 3 |
| 只用成对关系得分 | 79.78% / 79.01% / 79.22% | 2 / 4 / 4 |
| 成对关系与直接分类联合判断 | 79.80% / 79.18% / 79.21% | 2 / 4 / 4 |
| 打乱参考标签的联合判断 | 79.87% / 79.54% / 79.52% | 2 / 3 / 2 |
| 联合判断占强基线 25% | 81.72% / 81.25% / 81.06% | 0 / 0 / 0 |

从不同预订得到的比较样本并未提供高于直接分类的整体精度。可在现有带 PyTorch 的环境用 `.venv-tabpfn/bin/python passenger_relation_net_n23.py` 复现。[完整比较](result.json)
