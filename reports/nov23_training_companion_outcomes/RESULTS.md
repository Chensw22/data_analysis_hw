# 训练时使用同行结局，部署时能否得到更好的个人预测？

6,954 名开发乘客中，2,829 人在同笔预订中至少有一位开发集同行。每名乘客的辅助字段只使用其他人的结局，逐个改变本人的标签验证了本人字段保持相同。在外层训练订票中进一步划分订票组，生成教师的折外软标签。只看本人登记、账单和订票人数的学生各用一半真实标签与一半软标签训练。比较使用同行结局的教师和普通教师。另以个人预测独立抽样同行可能结局，在 24 次模拟中平均；所有可部署预测均不读验证乘客或同行的真实结局。

| 方法 | 全体准确率 | 有已标注同行的 2,829 人准确率 |
|---|---|---|
| 普通模型 | 81.35% / 81.32% / 81.02% | 82.96% / 83.10% / 82.79% |
| 从普通教师蒸馏 | 81.29% / 81.00% / 80.64% | 82.96% / 82.68% / 82.11% |
| 从获知同行结局的教师蒸馏 | 81.41% / 81.39% / 80.93% | 83.00% / 83.35% / 82.22% |
| 模拟未知同行结局 | 81.39% / 81.22% / 81.23% | 83.03% / 83.00% / 82.79% |

蒸馏对照中，同行教师相对普通教师三次净多答对 8、27、20 人。相对直接用真实标签训练的普通模型，净变化为 +4、+5、−6 人。将同行蒸馏模型按 25% 权重混入强基线，三次净增 −1、+21、−8 人，反复错且账单相同的 430 名地球乘客中分别纠正 8、8、12 人。

单列的诊断允许模型在预测时知道其他验证乘客的真实结局，三次全体准确率为 81.46%、80.97%、81.32%。这项诊断用来估计该模型利用同行信息的效果，未进入任何拟提交方案。[所有诊断和可部署预测](result.json)
