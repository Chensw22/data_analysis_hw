# 专门寻找基线错例，能否让改判精度达到 85% 所需水平？

6,954 名开发乘客中，1,070 人在三套整订票组验证里反复被强基线判错。若只改风险最高的约 10% 乘客，为使全体准确率严格超过 85%，三轮要在 695、695、697 名被选者中分别找到至少 **460、475、475** 个真错例。每多找到一个真错例并替换掉一个误选者，全体净收益相差两人。三套划分使用同一批乘客，v131 另用原划分回放，并保留既有改判。

| 用来选风险最高约 10% 乘客的依据 | 第一轮真错例 / 改判人数 | 第二轮 | 第三轮 |
|---|---:|---:|---:|
| 原始强基线置信度 | 321 / 695 | 362 / 695 | 332 / 697 |
| 学习对所有正确预测与错例的排序 | 310 / 695 | 332 / 695 | 315 / 697 |
| 学习压过最容易被误改的一成正确预测 | 296 / 695 | 327 / 695 | 319 / 697 |

排序器同时读取乘客资料和多个一级模型的分数。最后一行最优化的是配对平方间隔损失中最差一成正确样本的平滑尾部风险。以其他订票组估计改判精度，仅在预计有超过一半机会改对时行动，三轮实际纠正/新增错误为 126/150、185/185、146/180。稳定纠正 3/1,070 人。在 v131 回放纠正 122 人、新增错误 169 人。排序训练、概率校准与评估使用互不重合的订票组。[完整预算、部分 ROC 面积及校准结果](ranking.json)

## 如果账单和登记里确有一个可学的错误规律

保持全部人的原始分数和输入不动，在每个独立订票组留出块内，按照基线方向和风险五档重新分配一部分错例，保持各档错误人数及全体基线准确率完全相同。简单规律使用年龄、舱侧、客房服务与餐饮金额的加权和；交互规律使用年龄和舱侧的组合，以及两项消费差值的非线性变换。未获知公式的树模型仍然只能从原有数据学习。下表为改判后的全体准确率，只有第一行采用原始结果。

| 错误的形成方式 | 三套验证准确率 |
|---|---|
| 原始实际结果 | 81.33%、80.74%、81.18% |
| 同风险档内随机重排 | 80.89%、81.09%、81.06% |
| 在每档抽取半数乘客，把其中既有错误按简单规律重排 | 83.38%、83.39%、83.06% |
| 在每档抽取半数乘客，把其中既有错误按交互规律重排 | 82.05%、82.64%、81.78% |
| 将每档全部错误按交互规律重排 | 88.73%、89.85%、89.30% |

错例重排只检验流程对这几种已知信号的敏感度。另一项实验固定一级模型，将校准规模从约 128 人增至 2,028 人；全量校准的三轮实际净收益为 0、+38、0 人，v131 净少 17 人。现有资料下尚未观察到随校准集扩大而稳定增长的全体收益。[重排对照及对规律知情的参考模型](power.json) · [独立校准样本量实验](../nov23_error_calibration_size/RESULTS.md)

## 真实错例的登记或账单是否更异常？

用未标注传送结果的训练和测试名册学习 24 个二元潜在因素，以其余 13 个字段预测第 14 个字段。20% 的订票组专用于检验重建。在这些组上，平均字段预测对数损失为 1.067，按各字段总体频率预测为 1.419，在独立打乱各列的名册上拟合为 1.423。该模型学到了真实的字段依赖。

按基线原判方向分别比较，在各自 20 个风险档内衡量每个字段相对其他乘客有多异常。14 个字段、两个改判方向共 28 项对比，错例和正确预测之间最大的加权平均差异仅为 2.35 个百分位，所有按订票组计算的同时 95% 区间均包含零。直接用这些异常程度选择改判，三轮纠正/新增错误为 51/60、76/90、54/71。另对潜在因素的不确定性积分，允许三种错例类型混合，稳定纠正 21/1,070 人，但三轮净变化为 −21、+21、−24 人。[无标签模型和乱序对照](manifest_energy.json) · [逐字段效应和未见组预测](atypical_fields.json) · [潜在类别的错误概率](latent_error_odds.json)

## 联合模型与独立新主干

从 12 个不同一级模型里任选至多四个，穷尽全部 794 种选择。在基线原判方向和六个风险档内，允许每种投票组合任意决定是否改判。即使使用整个评估集的真实答案来挑选，该特定类别的规则最高只有 83.09%、83.15%、82.97%。只用其他订票组选择全体净收益最高的规则，再应用到未见组，准确率分别为 80.60%、80.89%、80.01%。对不同组合的可信度做概率加权后分别为 81.35%、81.75%、81.45%。该上限只针对指定的四票查表规则。[组合数、精确上限和独立验证](tables.json)

另一项新主干联合学习七个非线性投影方向，独立稳定判对 70/1,070 人，其中 22 人是固定投影和线性对照都未稳定纠正的。与强基线联合，三次准确率为 81.68%、81.49%、81.18%，只保留 3 人稳定纠正。[方法与独立模拟对照](../nov23_learned_indices/RESULTS.md)
