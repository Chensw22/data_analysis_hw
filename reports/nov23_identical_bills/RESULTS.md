# 五笔账单完全相同时，登记信息能分清结局吗？

仅用每个训练折的乘客找出五项账单金额及缺失位置都相同、却同时出现过传送和未传送的账单组合。然后预测未见订票组中具有这些账单的乘客，其他人保留原基线。三套评估分别覆盖 2,938、2,939、2,937 人；每次均包含全部 1,070 名反复错例中的 493 人，以及 804 名地球反复错例中的 430 人。后一个比例为 53.5%。已知全体标签后，八种账单组合有两种结局，其中五笔均为零、完整记录者达 2,624 人。

| 使用的信息 | 这些相同账单乘客的准确率 | 地球相同账单乘客的准确率 | 全体 6,954 人的准确率 |
|---|---|---|---|
| 同账单训练乘客的传送比例 | 78.76% / 78.77% / 78.75% | 63.33% / 63.35% / 63.30% | 81.13% / 80.67% / 80.69% |
| 加入本人登记、舱位和订票人数 | 80.57% / 79.72% / 80.12% | 65.71% / 63.43% / 64.74% | 81.90% / 81.08% / 81.26% |
| 再加入同订票其他人的登记和消费概况 | 80.16% / 80.30% / 79.40% | 64.48% / 64.87% / 63.45% | 81.72% / 81.32% / 80.96% |
| 原强基线 | 80.26% / 80.33% / 80.39% | 64.19% / 64.43% / 64.89% | 81.77% / 81.33% / 81.38% |

本人登记信息在三套划分中均比仅用账单频率更准。但与现有强基线相比，全体分别净增 9、−18、−8 人。加入同订票其他人概况后净增 −3、−1、−29 人。这组实验显示相同账单可以对应完全不同的乘客，现有登记数据解释了部分结局差异。它没有为这些乘客的可预测性给出上限。[覆盖范围与纠正、误伤计数](result.json)
