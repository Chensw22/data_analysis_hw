# 全体乘客的组合能纠正多少共同错例

开发集共 6,954 人。三套整订票组验证使用同一批乘客。强基线至少错过一次的有 1,518 人，三次全错的有 1,070 人，其中 509 人在此前 50 种候选中均没有被一个模型连续三次答对。三种新模型均从可见乘客属性出发，历史名单仅用于评估。

| 新方案 | 三套全体纠正 / 新增错误 | 1,518 人中稳定判对 | 1,070 人中稳定判对 | 509 / 172 人中稳定判对 |
|---|---|---:|---:|---:|
| 从相似乘客间的方向性差异校正强基线 | 125/129、137/116、133/145 | 107 | 19 | 1 / 0 |
| 从相似乘客的传送总人数学个人倾向，独立预测 | 270/421、242/375、214/372 | 228 | 75 | 2 / 0 |
| 按乘客属性学习不同的误差尺度，独立预测 | 248/385、246/382、255/394 | 249 | 95 | 6 / 0 |

第一种模型用登记资料、消费或两者一起寻找其他订票组的相似乘客，学习两个端点之间的结果差，再用全图最小二乘估计个人分数。完全相同的消费记录用随机等概率抽取的参照乘客处理。三个对照分别将差异固定为零、独立预测两端再相减、直接使用逐人预测。学习乘客对能预测一部分实际结局差异，但在强基线已经估计过的风险之上，留出两端的误差差异未获得稳定改善。v131 原始划分回放纠正 122 人、新增错误 146 人。[正式处理](../nov23_broad_passenger_differences/balanced.json) · [近邻实现的并列次序对照](../nov23_broad_passenger_differences/results.json)

第二种模型三次将训练乘客分成每组通常八人的小组，每组成员来自不同订票，同一乘客可出现在不同分组方案中。用每个组实际传送人数的精确概率拟合个人倾向；模型目标只接收各组的计数。与相同特征、相同正则化下的逐人标签或随机分组计数比较，相似分组没有显示稳定优势。用它校正 v131 时纠正 203 人、新增错误 213 人。第三种模型允许不同消费组成及缺失状态的乘客有不同的误差尺度，在 509 人中稳定判对的 6 人有 1 人此前扩展至 65 种候选仍未被稳定判对。将该尺度用于强基线校正之后，v131 纠正 132 人、新增错误 162 人。[组计数实验](../nov23_broad_count_supervision/results.json) · [误差尺度实验](../nov23_broad_latent_scale/RESULTS.md)

## 只用这批模型的分数，能否通过调整组合达到 85%？

对一组固定的模型分数，要求每个模型的传送分数增加时，组合对传送的判断不能下降。此限制包括任意非负加权平均和任何统一阈值，也允许非线性组合。如果一名实际传送乘客在所有坐标都低于或等于一名实际未传送乘客，则两人不能同时判对。用二分图匹配给出至少要错多少人，再构造一个恰好达到该错误数的规则。这里的上限使用了被评分乘客的标签。每套划分独立求解，规则在该划分内对所有人相同。

| 输入的概率分数 | 三套划分中事后可达到的最高准确率 |
|---|---|
| 基线加本轮三个独立模型 | 83.16%、83.09%、82.64% |
| 基线加三个模型各自对基线的校正 | 83.09%、82.99%、82.41% |
| 基线加 25 个具有完整独立一级预测的候选 | 93.89%、93.67%、93.74% |
| 基线加历史 65 个候选中与基线同档或更好的 29 个 | 87.23%、87.07%、86.97% |
| 基线加历史 65 个候选 | 96.17%、95.79%、95.80% |

在第一行，已穷尽上面定义的组合类别，继续调统一权重和阈值无法达到 85%。分数更多时，乘客之间同时在所有坐标上排出相同顺序的情形变少，按已知标签构造规则更容易。这些更高的上限不能外推到未知结果。强制优先把 509 人尽可能多地判对，再在该条件下最大化整体准确率时，25 个候选加基线分别最多能纠正其中 485、479、487 人，整体相应降到 66.39%、65.75%、61.71%。不同划分纠正的对象会变化。[最大匹配、独立的凸组合验证](results.json) · [加权最小割及全档位比较](wide_frontier.json)

按乘客的原籍、消费、休眠、舱侧和年龄允许每个群体使用不同的组合，四个分数的事后上限可超过 85%。将相同大小的群体随机分给乘客也会出现类似现象。只在其他订票组学习分组规则再预测时，真实细分规则三次分别净少判对 46、40、25 人。[分组与等规模随机对照](stratified.json)

## 在新订票组上能学到多少

给定基线和 25 个独立候选，使用其他订票组学习组合后在未见组评估。优先训练共同错例的规则仅使用校准集自身的基线错例和候选投票构造训练权重。打乱对照在基线风险接近的校准错例中重新分配相同权重。

| 实际可用的组合 | 全体三次纠正 / 新增错误 | 1,518 / 1,070 / 509 / 172 人中稳定判对 |
|---|---|---|
| 平滑模型的线性对照 | 90/77、106/88、108/95 | 93 / 6 / 1 / 0 |
| 分段非线性平滑组合 | 197/226、208/226、267/275 | 148 / 30 / 1 / 0 |
| 对校准集中意见一致的错例加权 | 187/310、217/340、205/299 | 122 / 59 / 17 / 0 |
| 相同错误权重在校准集内随机分配 | 150/261、209/297、187/277 | 103 / 46 / 14 / 0 |

线性对照三次全体准确率为 81.95%、81.59%、81.56%。只使用本轮三个新模型和基线的线性对照在 v131 原始划分上纠正 42 人、新增 50 个错误，准确率为 81.31%；25 个候选的线性组合只在三套整订票组划分验证。平滑非线性方案在已知为非线性的模拟独立样本上达 82.30%，线性对照为 73.17%。在真实乘客上，非线性方案多纠正了一些共同错例，也改错了更多原本正确的人。[独立校准和模拟对照](smooth.json)
