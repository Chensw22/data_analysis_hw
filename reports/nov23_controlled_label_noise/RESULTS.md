# 反复错例能否通过训练标签筛选改善？

对每套外层订票分组使用两个独立初始化的网络。它们在同一小批乘客上分别选择损失较小的训练例给对方，逐步过渡到每个观测类别剔除约 10%。同时进行干净对照和已知干预：只在当前外层训练折的内存副本中，按类别随机翻转 10% 的标签。最终验证标签与官方数据文件始终保持原值。[共同教学方法的原始论文](https://proceedings.nips.cc/paper_files/paper/2018/hash/a19744e268754fb0148b017647355b7b-Abstract.html)

| 外层训练时使用的数据与方法 | 三次验证准确率 |
|---|---|
| 原始标签，保留所有训练例 | 80.17% / 80.14% / 79.98% |
| 原始标签，两个网络互相筛选 | 80.27% / 80.10% / 79.78% |
| 加入已知翻转，保留所有训练例 | 80.27% / 79.88% / 80.04% |
| 加入已知翻转，两个网络互相筛选 | 79.44% / 80.08% / 79.57% |
| 加入已知翻转，按真实翻转位置剔除 | 80.11% / 80.13% / 80.10% |

在九个折中，进入稳定筛选阶段后，被网络剔除的训练记录里确实发生过人为翻转的占 47.3%–54.4%（随机选择时约 10%）。这说明大损失含有标签异常信号，但仍混有大量原本正常的困难样本。原始标签下，把筛选后的模型按 25% 权重加入强基线，三次净少答对 31/27/36 人；在 430 名相同账单的地球反复错例中分别纠正 17/9/22 人。本实验没有证据将任何原始标签判定为错标。[逐折人为翻转识别率与全体误伤](result.json)
