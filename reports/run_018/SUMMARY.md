# run_018：全局模型与休眠状态专家

固定v34全局模型，再加入CryoSleep True/False两个同特征CatBoost专家，已知状态以全局/专家各50%融合，未知状态保持原全局结果。专家训练轮数仅通过各状态outertrain内20%验证选择，再fresh重训全部状态训练行。
