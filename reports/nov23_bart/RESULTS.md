# 贝叶斯加性树能否识别基线漏判？

根据登记、舱位、五项消费及其总额、服务项数、部分消费占比和预订人数，使用 probit 贝叶斯加性回归树对传送概率进行后验采样。每折两条链，各留 64 次抽样，概率在每次抽样上分别做正态分布变换后求均值。对照梯度提升树使用相同特征矩阵，所有预测使用完整留出的预订。[StochTree 官方二分类说明](https://stochtree.ai/vignettes/probit.html)

| 6,954 位开发乘客 | 三套准确率 | 480 名持续漏判中各套找回 | 267 名共同漏判中各套找回 |
|---|---|---|---|
| BART 后验均值 | 80.54% / 80.10% / 80.46% | 58 / 51 / 54 | 1 / 0 / 3 |
| 相同特征的梯度提升树 | 81.13% / 81.09% / 81.02% | 24 / 23 / 35 | 0 / 1 / 1 |
| BART 占强基线的 25% | 81.61% / 81.49% / 81.41% | 9 / 9 / 8 | 0 / 0 / 0 |
| 后验抽样九成以上同向才采用 BART | 81.42% / 81.13% / 81.18% | 13 / 13 / 18 | 0 / 0 / 0 |

两条链给同一乘客的平均预测差，中位数为 0.033–0.035，95% 分位仍为 0.154–0.160。对这些差异较大的乘客，短链结果不能作为模型已充分收敛的证据。[逐方向结果与两链差值](result.json)
